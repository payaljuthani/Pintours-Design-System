Icons

PinTours uses Tabler Icons — 5,000+ outline icons, MIT licensed. Use currentColor so icons inherit semantic color tokens from their parent.

Shadows

Button

Allow users to trigger actions, submit forms, or navigate. Three types, three sizes, five states.

Button Icon Only

A square button that holds a single icon — no label. Three types, three sizes, five states. Picks up the same icon chosen in the Button playground.

Filter Chip

Let users toggle filters or select categories. Four states (Default, Highlighted, Active, Outline) across three sizes, with an optional leading icon.

Eyebrow Highlight

Compact status labels that sit above content to signal intent. Five semantic states, two type variants (Light and Dark), with an optional leading icon.

Tag

Inline labels used to categorise or annotate content. Five semantic states, two type variants (Light and Dark), with an optional leading icon.

Super Icon

A wrapper that pairs any Tabler icon with a container shape and state. Swap the icon from the library below — the shape, size, and color tokens update across all platform snippets.

Map Pin

Numbered location markers for tour stop sequences. Three states — Default (upcoming), Selected (active), Visited (completed). Type any number in the picker and all three states update live.
